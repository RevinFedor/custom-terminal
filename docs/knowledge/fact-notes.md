# Feature: свободные заметки вкладки — удалено

## Текущее состояние

Пользовательская поверхность свободных Markdown-заметок вкладки удалена. В интерфейсе больше нет кнопки заметок в строке вкладки, бокового редактора, Cmd-hover-превью, горячих клавиш редактора и секции настроек заметок.

Актуальная замена — структурированный двухуровневый план задач вкладки: [`fact-tab-task-plan.md`](fact-tab-task-plan.md).

## Совместимость старых данных

Поле `tab.notes`, колонки старых баз и отдельные внутренние обработчики могут оставаться в коде как совместимость с ранее сохранёнными данными. Они не являются действующей продуктовой возможностью и не должны возвращаться в UI без отдельного решения.

Старый Markdown-текст автоматически не превращается в задачи: свободный текст не даёт надёжно определить уровень абстракции, границы задач и их статусы. Новый план создаётся явно пользователем или через подтверждённое предложение нейронки.

## Исторические шрамы

Технические выводы старого редактора остаются в тематических `fix-notes-*`, `fix-codemirror-*` и дизайн-методологии. Они полезны для других редакторов, но не описывают текущий user flow вкладки.
