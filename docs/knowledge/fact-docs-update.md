# Feature: Обновление документации (удалено)

## Статус
Кнопка `📚 Docs` в шапке проекта и вся панель действий за ней удалены **2026-08-18**. Вместе с ними ушли оба пайплайна: «Update Docs → Gemini» (интерактивная вкладка `docs-XX` с Gemini CLI) и «Update API → Haiku» (внешний вызов Claude/Gemini + заранее заполненная сессия Claude).

Файл сохранён как объяснение того, **почему** этого больше нет, и куда переехал сценарий. Историю реализации смотри в git до этой даты.

## Почему удалили
Пайплайн был построен на механизмах, которые с тех пор заменены общими:
- **Ручное ожидание готовности терминала.** Три самописных ожидателя (`waitForGeminiReady`, `waitForGeminiSettled`, `waitForGeminiResponse`) ловили `[INSERT]` в выводе, держали «период тишины» и опрашивали спиннер в буфере xterm. Сегодня готовность и занятость агента приходят детерминированными событиями, а доставка задачи в другую вкладку — сценарный слой, а не запись в PTY.
- **Своя оркестрация вкладок.** Панель сама создавала вкладку, писала команду запуска, ждала ответ и закрывала вкладку при отмене. Это ровно то, что теперь делает Terminal MCP (`delegate_to_session` → уведомление → один `get_delegation_result`), но переживая рестарт и оставаясь видимым пользователю.
- **Сторонний прокси для Claude.** Запросы шли на внешний адрес с ключом, зашитым в исходник. Удаление убрало и эту поверхность.
- **Gemini CLI как рабочий агент.** Интерактивный `gemini -y -r` и headless `gemini -p` больше не используются; актуальные ветки — Claude и Codex.

## Как обновлять документацию сейчас
Обычной Claude/Codex-вкладкой:
1. Разбор существующей документации по подсистеме — MCP `docs_search` (primary-канал, до `rg`/чтения файлов).
2. Длинная работа между вкладками — Terminal MCP `delegate_to_session`: доставка возвращает `runId`, завершение приходит отдельным уведомлением, результат читается один раз.
3. Переиндексация — MCP `docs_reindex` с явным `projectPath`.

## Что осталось в коде от старого пайплайна
Ничего от самого пайплайна. Уцелели только вещи, которые он **переиспользовал** и которые живут своей жизнью:
- `claude:export-clean-session` и `gemini:copy-range` — экспорт сессии (кнопка копирования сессии, Timeline). См. [`fact-export-session.md`](fact-export-session.md).
- Общий вызов Gemini API — модели, названия вкладок, пересказы Timeline, группировка, сжатие при Rewind, сообщение коммита. Функция для main-процесса переехала в `src/main/ipc/gemini-api.js`; к документации она отношения не имела никогда.
- Флаг `skipProcessCheck` в закрытии вкладки — см. [`fact-tabs.md`](fact-tabs.md).

## Что удалено вместе с кнопкой
`DocsButton.tsx`, `panels/ActionsPanel.tsx`, `UI/ApiSettingsModal.tsx`, `src/main/ipc/docs.js` целиком; заготовки сессий `claude:create-prefilled-session` и `gemini:create-prefilled-session`; ветка `resumeSessionId` в запуске Gemini; настройки «Documentation» и «Post-check» в Settings; тумблеры Auto-apply и Post-check; общее состояние выделения текста в терминале (его читала только кнопка «ножницы»); проверка спиннера Gemini в буфере; мёртвые обработчики глобальных команд.
