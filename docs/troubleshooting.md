# Ошибки и диагностика

| Что видно | Что проверить и сделать |
|---|---|
| `npm ci`/native build упал | Node22, Python3, Xcode Command Line Tools и полный checkout. Сохранить первую compiler/dependency причину; повторный install не заменяет её. |
| `node-pty ... SHA/toolchain drift` | Пакет/headers/версии отличаются от pinned build. Не отключать guard. Вернуться к lockfile и `npm ci` в отдельной чистой копии. |
| CLI не найден | `command -v claude`/`codex`, версия, PATH внутри запускаемого shell. Finder и login-shell могут иметь разные PATH. |
| Требуется login | Открыть тот же native terminal, войти вручную и дождаться input-ready. Не вставлять keys в composer. |
| Claude403/429 или settings error | Сохранить безопасную provider reason. Доступ/лимит аккаунта не исправляются повторным перезапуском. Выбрать доступную настройку/повторить после устранения причины. |
| Вкладка есть, Send не готов | Проверить процесс, startup/dialog, фактические settings и готовность ввода по отдельности. Не считать PID разрешением Enter. |
| Рабочая папка исчезла | Указать существующий cwd. История и место исполнения различны; не удалять историю ради новой папки. |
| MCP не появился | Managed registration, Node/path, свежий CLI inventory. Hub restart не перечитывает native config старой сессии. Optional adapter отсутствует, пока не установлен и не настроен. |
| API не отвечает/401 | Работающий app, actual port/listener, адрес этого Mac и его token. Не использовать URL/credentials другого пользователя. |
| Отправка получила timeout | Прочитать прежнюю receipt/run/result. Unknown не равен отказу и не разрешает новый Send. |
| История устарела после reconnect | Получить snapshot/delta текущего read owner. Idle не подтверждает свежесть уже показанной History. |

## Экспорт TXT

В работающем приложении откройте справку и экспорт логов. Выберите период:
15мин — ошибка только что;1час — несколько попыток;24часа — раньше/время неизвестно.
Опишите кратко, что ожидалось и что произошло, примерно когда и в какой вкладке.
Описание необязательно, если оно уже передано вместе с файлом.

Текстовые фрагменты включайте для пропавшего/обрезанного/дублирующегося текста,
ошибки вставки или расхождения сообщения с History. Для зависания, build/login
и подключения обычно достаточно технического лога. Экспорт не получает всю
переписку: он только оставляет текст, который уже попал в runtime log.

Файл сохраняется локально, после сохранения доступен «Показать в Finder». Известные
credential формы очищаются, но free text/кадры терминала могут содержать личные
сведения. Просмотрите файл перед отправкой. ID/path/frame metadata полезны для
диагностики; выключенный checkbox не означает отсутствие любого текста терминала.
Полные Claude/Codex transcripts не прикладываются автоматически.

Если строк за выбранный период нет, увеличьте период и проверьте logger/source.
Пустой созданный файл не доказывает отсутствие ошибки. Timestamps runtime log —
UTC; сообщите своё локальное время и timezone, чтобы интервал был пересчитан правильно.

## Приложение не стартует

Finder → Go to Folder → `~/Library/Logs/noted-terminal/` для packaged runtime;
source dev пишет `logs/dev.log` в checkout. Проверьте текущий/предыдущий log и
macOS crash report. Raw log не прошёл экспортную очистку и может содержать private
text; не публикуйте его целиком в GitHub issue. Сначала приложите version/architecture,
не пройденный шаг и очищенную конкретную причину. Не сбрасывайте БД/auth/transcript
ради устранения build/permission ошибки.
