# API-ключи и ENV

Для обычного входа в Claude Code или Codex используется авторизация самого CLI.
API-ключи Noted нужны только для выбранных дополнительных сервисов.

| Переменная | Когда нужна |
|---|---|
| `GEMINI_API_KEY` | AI-названия, описания, summaries и Gemini AI-Rewind |
| `OPENCODE_ZEN_KEY` | Claude-compatible provider Zen |
| `DEEPSEEK_API_KEY` | Provider DeepSeek |
| `SONIOX_API_KEY` | Голосовая диктовка Soniox |
| `ANTHROPIC_ADMIN_API_KEY` | Необязательное административное чтение provider usage |

Пример без значений: [`.env.example`](../../.env.example). Для dev-запуска
скопируйте его в `.env` в корне своего checkout и укажите только нужные ключи:

```bash
cp .env.example .env
chmod 600 .env
```

Уберите `#` перед выбранной переменной и впишите значение после `=` без кавычек.
Для собранной `.app` основной файл — `~/.noted-terminal/.env`. Main также читает
`.env` рядом с executable, если он существует; значения из него читаются позже.
Новые значения применяются при следующем запуске соответствующего приложения.

Файлы с реальными значениями не входят в Git. Не добавляйте их в context attachments,
issue или сообщения AI. В renderer-исходники и JS-сборку ключ не встраивается:
существующие Gemini-действия получают его из runtime Electron main через локальный IPC.

Token подключения Noted API — отдельный секрет в `~/.noted-terminal/web-token.txt`.
Он не является ключом провайдера; подключение клиента описано в [API](../api.md).

Если ключ когда-либо был опубликован, удаление из Git не отзывает его. Замените его
у провайдера и обновите локальный ENV. Это касается и старых, уже удалённых версий.
