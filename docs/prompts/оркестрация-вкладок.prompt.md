# Оркестрация AI-вкладок

Оркестрируй Claude/Codex через Project API Noted Terminal. Не используй Overseer для отправки, ожидания или получения финального ответа: Overseer нужен только для ручного чтения истории. Не читай ответ из terminal output.

Найди живой локальный сервер и токен. Discovery-файлов может быть несколько после dev/prod запусков, поэтому проверь `/api/me`, а не бери слепо самый новый:

```bash
TOKEN=$(cat ~/.noted-terminal/web-token.txt)
for DISCOVERY in $(ls -t ~/.noted-terminal/web-server-*.json); do
  PORT=$(jq -r '.port' "$DISCOVERY")
  CANDIDATE="http://127.0.0.1:$PORT"
  curl -sf -H "Authorization: Bearer $TOKEN" "$CANDIDATE/api/me" >/dev/null || continue
  BASE_URL="$CANDIDATE"
  break
done
test -n "$BASE_URL" || { echo "Noted Terminal API не найден" >&2; exit 1; }
```

Для другого компьютера не ищи локальный discovery-файл: получи у владельца Noted Terminal `BASE_URL=http://<IP>:<port>` и bearer-токен, затем используй те же endpoint'ы.

Получи проекты и вкладки через `GET /api/projects` и `GET /api/projects/:projectId/tabs`. Затем создай асинхронный запуск:

```bash
curl -sS -X POST "$BASE_URL/api/orchestrations" \
  -H "Authorization: Bearer $TOKEN" \
  -H 'Content-Type: application/json' \
  -d '{
    "sourceTabId": "<вкладка-оркестратор>",
    "targetProjectId": "<проект>",
    "toolType": "claude",
    "name": "<имя новой вкладки>",
    "prompt": "<задача>",
    "notifySource": true,
    "queue": true
  }'
```

Новая вкладка создаётся в фоне. Если исполнитель уже существует, передай `targetTabId` вместо `targetProjectId`, `toolType` и `name`. POST возвращает `202` и `run.runId`; он подтверждает отправку, а не готовность ответа.

Не держи запрос открытым и не запускай polling. Завершение придёт коротким сообщением в исходную вкладку. После него выполни ровно один `GET /api/orchestrations/:runId/result`. Для UI-клиента подпишись на `GET /api/events?token=<token>&tabId=<sourceTabId>` и жди `orchestration-update` со статусом `completed` или `failed`. Текущее состояние при необходимости читается одним `GET /api/orchestrations/:runId`, отмена — `POST /api/orchestrations/:runId/cancel`.

В History верхний блок показывает только активные вызовы. Завершённые находятся в компактном окне `History`; клик по записи открывает связанную вкладку, в том числе в другом проекте.
