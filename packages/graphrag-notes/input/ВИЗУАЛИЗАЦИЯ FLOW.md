│                                                  │

               │
               ▼
┌──────────────────────────────────────────────────┐
│  ЭТАП 3: ГОТОВАЯ ЗАМЕТКА (10-15 минут)          │

│  │                                                │
│  └─ СВОДКА (редкий)                              │
│     - Несколько механизмов в едином нарративе    │
│     - Трансформация / Closure / Комплексный кейс │
│     - История + секции по механизмам             │

               ▼
┌──────────────────────────────────────────────────┐
│  РЕЗУЛЬТАТ: Готовая заметка в Obsidian           │
│                                                  │
│  - Легко найти через keywords                    │
│  - Механизм ясен                                 │
│  - Применение конкретное                         │
│  - Можно использовать при панике/проблеме        │
└──────────────────────────────────────────────────┘

## СХЕМА: ПРИНЯТИЕ РЕШЕНИЙ

```
┌─────────────────────────┐
│  НОВОЕ СОБЫТИЕ          │
└────────┬────────────────┘
         │
         ▼
    ┌─────────────────┐
    │ Есть мысли?     │
    └────┬────────────┘
         │
    ┌────┴──────┐
   ДА          НЕТ
    │            │
    ▼            ▼
┌──────────┐  ┌──────────────┐
│ Долгая   │  │ Короткая     │
│ история? │  │ строка?      │
└─┬──────┬─┘  └──┬───────────┘
  │      │       │
 ДА     НЕТ    ДА
  │      │      │
  ▼      ▼      ▼
┌───┐  ┌───┐  ┌───┐
│Obs│  │Obs│  │ TG│
│сыр│  │кейс│  │   │
│ая │  │    │  │   │
└───┘  └───┘  └───┘

```

**Вопросы для принятия решений:**

1. **Есть ли мысли/инсайт?**
   - НЕТ → TG (простой факт)
   - ДА → продолжай

2. **Механизм ясен сразу?**
   - НЕТ → Obsidian сырая
   - ДА → продолжай

3. **Сколько механизмов?**
   - 1 → Obsidian кейс
   - 2+ независимых → несколько заметок
   - 2+ связанных → Obsidian сводка

## TIMELINE ПРИМЕР

```
День 1 (Воскресенье)
└─→ Поездка в Сочи, много событий
    └─→ 5 минут: сырая заметка в черновики

День 2-6 (Понедельник-Пятница)
└─→ Заметка лежит, не трогаешь

День 7 (Суббота - ревью)
└─→ 30 минут: смотришь все сырые заметки за неделю
    └─→ Поездка в Сочи: вижу 3 механизма
        └─→ 30 минут: создаю 3 готовые заметки

ИТОГО: 5 мин фиксация + 60 мин обработка = 65 минут
```

## ЧТО ВАЖНО

✅ **Не думай над механизмом при записи** - просто фиксируй
✅ **Ревью раз в неделю** - не каждый день
✅ **Одна история может дать несколько заметок** - это нормально
✅ **Не все сырые заметки станут готовыми** - это тоже нормально
✅ **Простые факты → TG** - не загромождай Obsidian

❌ Не пытайся сразу найти механизм
❌ Не пытайся сразу дать название
❌ Не обрабатывай каждую заметку сразу
