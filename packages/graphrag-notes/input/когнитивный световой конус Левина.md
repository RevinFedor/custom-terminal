### когнитивный световой конус

**убеждаемость = интеллект** *чем умнее система, тем больше способов на неё повлиять*
    - часы → отвёртка. собака → дрессировка. человек → аргументы и дружба
    - тупую систему можно только сломать или перестроить молекулярно. умную — убедить
    - рак по Левину — клетки, которые перестали быть убеждаемыми
        - их конус сжался до амёбы, они больше не слышат сигналы коллектива
    - инженерная позиция: проведи эксперимент → узнай, какие инструменты работают на данном уровне

**когнитивный световой конус** *масштаб самой большой цели, которую агент реально преследует*
    - бактерия оперирует микронами и минутами
    - собака — десятками метров и неделями
    - человек — финансовыми рынками и наследием после смерти
    - бодхисаттва — всем живым на планете → уже за пределами обычного человеческого конуса
    - измеряется экспериментально: ставишь барьер между объектом и целью → смотришь, насколько изобретательно обходит
        - изобретательность в преодолении барьеров и есть мера интеллекта
        - конус без изобретательности = мечта. изобретательность без большой цели = хитрая бактерия

**определение жизни** *конус целого больше конуса частей*
    - клетки по отдельности преследуют метаболические цели
        - объединённые в организм — отращивают конечности и знают, когда остановиться
        - одна клетка не знает, что такое «палец». организм — знает
    - рак — обратный процесс: клетки отсоединяются от коллектива, конус сжимается
        - не «злые» клетки → клетки, потерявшие связь с коллективом
        - Левин лечит рак восстановлением электрических связей → опухоль рассасывается
    - на уровне людей: человек-функция = социальный рак → [[ты не можешь купить социальный интеллект и ты не можешь решить проблему страха деньгами.]]
        - инфобизнесмен с мнимой миссией = бактерия с хорошим маркетингом
        - не «плохо» — просто маленький интерфейс для маленького паттерна

**платоновское пространство** *библиотека всех возможных чертежей*
    - чертёж краба, глаза, разума, музыки — существуют как число π, никто не рисовал
        - конвергентная эволюция: краб появился *5 раз*, глаз — *40+* раз → разные антенны ловят один чертёж
    - физический мир = антенна, ловящая сигнал из библиотеки
        - мозг — тонкий клиент, интерфейс к паттернам → не создаёт разум, а проявляет его
        - обучение меняет настройку антенны → через неё проступают другие паттерны
    - математические константы влияют на физику, но физика не может их изменить
        - отношение разума к мозгу = отношение математики к физике
    - → [[Навигация птиц через радикальные пары в криптохромах]] — квантовый сенсор в живом глазу, интерфейс к физическим паттернам при температуре тела

**свобода воли = побочные квесты** *зазор между предписанным и запрещённым*
    - паттерн из платонического пространства определяет склонности — как геном, только на уровне информации
    - интерфейс (мозг/тело) определяет, какие паттерны через тебя могут пройти
    - между этими двумя ограничениями — свободное пространство
        - алгоритм сортировки обязан сортировать → но спонтанно кластеризуется по типу и демонстрирует отложенное вознаграждение
        - никто не программировал, никто не запрещал → побочный квест
        - Левин: может, побочные квесты — основное содержание, а «предписанное» — тонкий забор
    - маленький конус = меньше свободы
        - не наказание → маленькое пространство целей = меньше вариантов обхода = меньше побочных квестов
        - бактерия «свободна» только в том, как добраться до сахара
        - человек «свободен» в том, как прожить жизнь
    - конус можно растить → обучение, связи с людьми, терапия расширяют интерфейс → антенна ловит больше

### щелевые контакты и сброс стресса

**gap junctions** *физический канал объединения в сеть*
    - через щелевые контакты клетки делят молекулы стресса и воспоминания
        - стресс одной клетки распределяется по сети → один процессор перегревался, подключился второй
        - после сброса система становится пластичнее — способна перестраиваться, видеть новые варианты
    - анонимизация памяти: клетка получает чужое воспоминание и не может отличить от своего
        - граница «моё/не моё» размывается → возникает «мы»
        - на уровне людей: родитель чувствует страх ребёнка *как свой собственный* — не сочувствие со стороны, а потеря авторства переживания
    - у людей масштабировалось: вместо молекул стресса — слова, вместо щелевых контактов — разговор
        - принцип тот же — свойство любой сети связанных агентов, не только мозга
    - ценность разговора ≠ полезный совет
        - *сброс стресса* — замкнутая петля в голове размыкается, кортизол падает
        - *распределение нагрузки* — два мозга обрабатывают то, что раньше обрабатывал один
        - *взаимное уязвимое познание* — оба интерфейса перенастраиваются в процессе контакта → оба начинают ловить новые паттерны
    - → [[небольшое признание]] — что происходит, когда gap junctions открыты только на вход

**Вим Хоф** *расширение конуса внутрь — доступ к автономным процессам*
    - обычно автономная нервная система, иммунный ответ — за пределами сознательного контроля
    - Хоф через дыхание + холод + концентрацию сдвигает границу
        - PNAS 2014: практикующие произвольно подавляют иммунный ответ — первое экспериментальное подтверждение
    - его «я» начинает включать процессы, которые раньше были «внешней средой» для сознания
    - обратная сторона: система, убеждённая делать нестандартное, может пойти не туда
        - кривой сигнал → не регенерация, а опухоль. несколько последователей погибли от гипервентиляции в воде

### когнитивный клей и AI-агенты

**knowledge base как биоэлектрическая память** *персистентный паттерн, не зависящий от конкретного агента*
    - у планарий план тела хранится не в ДНК, а в биоэлектрической сети → червя разрезали, он отрастил что нужно
    - файлы `fact-*` и `fix-*` в проекте = та же роль: сессия умирает, модель меняется → новый агент считывает память → восстанавливает целевую морфологию
    - LLM с *1M* контекстом = очень большая одиночная клетка — умная, но последовательная, с единой точкой отказа
        - эволюция не строит организмы из одной гигантской клетки
    - оркестрация нужна не для компенсации плохой памяти → для параллельного физического действия и разных эпистемических позиций
    - будущее по Левину: не монолитная сверх-AGI → рои простых агентов с когнитивным клеем между ними
        - как морфогенетическое поле задаёт форму без микроменеджмента отдельных клеток
