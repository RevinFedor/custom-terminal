**Суть:** Планирую реализовать функцию тегирования и ссылок между заметками через нейронку, где можно будет добавлять ссылки в конец заметок с кратким описанием в 2-3 словах.

---

Из ближайших реализуемых доступных нам фичей это у нас получается тегирование, ссылки на заметки — то есть просто функционал добавить ссылку в конец заметки либо там какой-то блок отдельно сделать. Можно будет его по шаблону красиво оформить, но шаблон делается относительно просто на самом-то деле.

То есть вопрос именно какие брать заметки — нам по сути только ссылки нужны и делать это чисто через нейронку из разряда какой-то промпт задать. И по сути делается это реально просто.

Единственное... ну то есть как с тегами нам по-хорошему эти заметки бы просматривать — и это первый момент. Второй момент — в будущем там скорее всего будет многоуровневая структура, то есть одна заметка ссылается на другую и та на следующую.

Но пока что это можно отображать в какой-то системе последовательности — типа допустим там ссылка на ту заметку она прямая, а ссылка на другую заметку она как бы вторичная, то есть от второго уровня там говорилось про ту заметку и так далее. Либо пока что можно кидать не ссылку а ссылку плюс описание в конец заметки типа буквально в 2-3 словах.

Это техническая задача, которая требует [[автономное-решение]] для системы организации знаний. Вопрос структурирования связей между заметками через [[реализация-целей]].
