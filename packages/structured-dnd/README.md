# @noted/structured-dnd

Headless-ядро для списков, где в одном порядке живут обычные элементы и группы с
дочерними элементами. Пакет общий для Custom Terminal и Voice Record; file explorer
использует его геометрические примитивы.

## Граница ответственности

Пакет владеет нормализованной моделью `containers + items`, переносом сущностей,
snapshot-геометрией grouped list, pointer-session и компенсацией CSS transform при
измерении. Он не владеет React-разметкой, визуальными токенами, IPC и способом
сохранения данных. Приложение адаптирует свои `group_id` / `groupId` к `containerId`
и передаёт стабильный ID каждой сущности.

Есть два допустимых preview-контракта. Если интерфейс переставляет строки прямо во
время жеста, после каждой перестановки нужна новая revision геометрии. Если preview
сам перемещает semantic target под курсором, например раскрывает пустую группу, цель
остаётся статичной на весь жест и итоговое состояние применяется атомарно на drop.

## Проверка

```bash
npm test
```

Тесты покрывают атомарное перемещение группы, вход/выход элемента из группы и
разделение верхней/нижней половины group header от nested body.
